## Motion

| Recommendation | Implementation |
| --- | --- |
| M01 | Short opacity-only route appearance preserves the existing history/scroll behavior without moving hit targets. |
| M02 | Stable pressed colors and local pending/success/error states retain button nodes and touch geometry. |
| M03 | Shelf, passage, discussion and account activity mutations update their affected section; failures retain context and offer local recovery. |
| M04 | Shared sheets use restrained appearance, opener focus return and visual-viewport height constraints with reduced-motion support. |
| M05 | Real-cover hero rotation pauses through a press; onboarding and prompts stop during active tasks or manual choice. |
| M06 | Reserved loading/cover space and local messages avoid replacing active page surfaces; no automatic manuscript motion is introduced. |
| M07 | Optional quiet reader controls have predictable pointer/keyboard reveal and remain visible while dialogs or keyboard focus need them. |
| M08 | Manuscript and passage saves distinguish saving, device recovery, pending changes and saved online; chapter endings remain quiet. |

Physical iPhone Safari/Chrome, native VoiceOver, translation and read-aloud need device validation. Viewport emulation and readable DOM checks cannot establish those native outcomes.
