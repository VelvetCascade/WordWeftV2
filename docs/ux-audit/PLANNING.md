# Planning, writer inbox and metric definitions

Approved findings: F08, F35–F38, F44–F45, plus writer controls for the reading agent's F48 contract.

- F08: visible associated labels cover character create/edit fields, scenes and chapter selection, private notes, and manuscript import. Opened-form accessibility verification is tracked below.
- F35: phone layouts show title, format and synopsis before the optional cover. Recovery remains supplied by the shared form hook; the optional cover can be added later.
- F36/F37: saved scenes and notes have explicit Edit actions, immutable edit buffers, local save errors, preserved unsent drafts and deliberate deletion. Scenes can change or remove their chapter link and change character membership. Private note title is optional; nonempty content is required, matching the UI. Successful edits update only the relevant record.
- F38: Story guide supports adding/editing inside the mounted chapter workspace. Closing preserves the editor and cursor context. Successful mutations dispatch `wordweft:planning-updated` with `{ bookId }` so guide data and editor mentions can refresh. Editor caller coordination: both WorldBuildingSidebar and chapter-private NoteList need `ownerId={currentUser.id}` (publishing agent owns those call sites).
- F44: per-story and All/New/Unanswered/Replied inbox filters. Replied means an answer from the current writer. New means reader activity since the previous inbox visit (first visit includes all reader activity). Passage links use `/book/:bookId/chapter/:chapterId?paragraph=N`, including paragraph zero; reading agent consumes the route. Reply forms use the shared per-user/per-thread recovery hook and update the successful thread locally without reloading the inbox.
- F45: chapter views means all-time chapter opens, including repeat opens. Reader identities combine the retained 400-day event window and legacy saved progress. Portfolio completion counts each reader once if saved progress reached at least 90% of a selected story; chapter Finished uses the same 90% threshold. The chart/table continue to show only 14 days. Distinct completion identities and unioned event/progress denominators prevent completion above 100%.
- F48 writer contract: descriptionVisibility PUBLIC by legacy default; goalVisibility PRIVATE by legacy default; explicit field controls; reader preview; optional spoilerDetails up to 2000 characters and spoilerChapterId chosen from published chapters. Reader/service/type/CharacterPreview projection remains owned by the reading agent. Private author goals continue to appear in the author's planning workspace.

## Required backend correctness

Scene/Note services previously lacked ownership checks, and scene updates ignored chapterId. Both services now require the signed-in story owner for every read/mutation, including chapter-scoped note reads. Creation clears supplied IDs to prevent arbitrary upserts; scene links validate same-story chapter and character ownership. Note edits preserve their original story/chapter association. Planning reads carry private/no-store and Vary Authorization headers. Ownership metadata uses manuscript-free book projections.
